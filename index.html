    使用说明

    学习转盘 · 一分钟上手

    1. 抽取任务 点击「抽取学习任务」或转盘中心的「抽取」，转盘停止后抽到的时长会自动记入任务栏。
    2. 计时规则 抽到学习任务，必须等倒计时结束才能再抽；抽到休息任务，可以随时点「跳过休息」抽下一轮。
    3. 任务栏 可勾选完成、删除记录、清空当日；用顶栏日期选择器可查看往日数据（只读）。
    4. 统计栏 切换今日 / 近 7 天 / 近 30 天查看累计数据，生成图表后可保存为 PNG，也可以随手收起。
    5. 数据备份 连接同步码后记录会自动保存到云端；也可在统计栏导出 / 导入 JSON 备份。
    进度云端同步 · 换设备填同一个同步码即可继续
    进度云端同步（Supabase · 免登录同步码）· 支持导出备份 · 快捷键 1-5 切换学科

    云同步（免登录）

    不需要注册账号。同步码就是钥匙：在每台设备的浏览器里填入同一个同步码，就能共享同一份进度 （看板与转盘共用同一个同步码）。

    当前同步码（本机已保存） 记住它，换设备要用
    —

    本机还没有保存同步码。如果之前在别的设备 / 浏览器连接过，请到那台设备打开本页查看； 也可以在 Supabase 的 SQL Editor 里执行 select code from public.boards; 找回（以 #turntable 结尾的是转盘记录，取前面的部分就是同步码）。

    第一次使用：弹窗会自动填好一个随机码，点「连接并同步」后把它记下来； 换手机 / 电脑时填同一个码即可继续。同步码相当于密码，请不要公开。

    还没有建库？

    配置 Supabase 云同步

    一次性配置，约 3 分钟。看板与转盘共用这一个同步码。

    1. 新建项目：打开 supabase.com 登录 → New project。创建完成后在 Project Settings → API 里复制 Project URL 和 anon public 密钥。
    2. 建表并创建读写函数：打开 SQL Editor，粘贴执行下面的 SQL（一次跑完即可）。 
      -- 1) 存放进度的表：一行 = 一个同步码
create table if not exists public.boards (
  code text primary key,
  progress jsonb not null default '[]'::jsonb,
  updated_at timestamptz not null default now()
);

-- 2) 表本身不对外开放，只允许通过下面的函数读写
alter table public.boards enable row level security;

-- 3) 读取某个同步码的进度
create or replace function public.load_board(p_code text)
returns jsonb
language sql
security definer
set search_path = public
as $$
  select coalesce(progress, '[]'::jsonb) from boards where code = p_code;
$$;

-- 4) 保存某个同步码的进度（不存在就创建）
create or replace function public.save_board(p_code text, p_progress jsonb)
returns void
language sql
security definer
set search_path = public
as $$
  insert into boards (code, progress, updated_at)
  values (p_code, coalesce(p_progress, '[]'::jsonb), now())
  on conflict (code) do update
    set progress = excluded.progress,
        updated_at = now();
$$;

-- 5) 只允许匿名前端调用这两个函数
revoke all on function public.load_board(text) from public;
revoke all on function public.save_board(text, jsonb) from public;
grant execute on function public.load_board(text) to anon, authenticated;
grant execute on function public.save_board(text, jsonb) to anon, authenticated;
    3. 填写配置：把上一步的 URL 和 anon key 填进仓库里的 js/supabase-config.js： 
      window.SUPABASE_CONFIG = {
  url: 'https://你的项目编号.supabase.co',
  anonKey: '你的 anon public key'
};
    4. 刷新页面并连接：重新打开本页面，点顶栏「设置同步码」→ 弹窗会自动填好随机码 → 点「连接并同步」并记下它。之后在手机 / 电脑上打开同一页面，填入这个同步码即可同步看板与转盘。

    安全说明：anon key 可以公开在前端；数据库表默认拒绝匿名直接读写，只能通过 load_board / save_board 两个函数按同步码访问，所以请把同步码当成密码保管。 请勿把 service_role 密钥写进前端。

    使用说明

    一分钟了解这个网站：进度看板、学习转盘、云同步。

    1. 选学科点顶栏「生理 / 病理 / 内科 / 外科 / 生化」，或按数字键 1~5 快速切换。
    2. 标记完成点击任务行或左侧复选框即可打勾，进度、章节完成数和总进度会实时刷新，并自动同步到云端。
    3. 找任务用功能栏的搜索框按关键词或页码查找；「隐藏已完成」只看没做的；「全部展开 / 收起」批量控制章节。
    4. 看统计点顶栏「统计 XX%」展开统计面板：总进度环、已完成 / 剩余、五个学科进度与剩余数量。再点一次或按 Esc 收起。
    5. 备份顶栏「导出」保存 JSON 备份；「导入」合并记录；「重置」清空全部完成记录（云端同步时云端也会清空）。
    6. 记住学科地址栏会带上 #学科id，刷新后仍停在这个学科。
    1. 进入转盘点顶栏「学习转盘」切换；也可以直接收藏网址加 #wheel，打开就是转盘页。
    2. 抽任务点「抽取学习任务」或转盘中心按钮。抽到学习任务后必须等倒计时结束才能再抽；抽到休息任务可点「跳过休息」继续。
    3. 任务与打卡抽到的时长自动记入任务栏；可勾选完成、删除单条、清空当日。用工具栏日期选择器可查看往日记录（只读）。
    4. 统计与图表统计栏支持今日 / 近 7 天 / 近 30 天；点「生成统计图表」可看环形图与柱状图，并「保存图表 PNG」。
    5. 数据备份转盘页的「导出数据 / 导入数据」只作用于转盘记录；「清空全部数据」也只清空转盘，不影响看板进度。
    1. 不用注册数据存在你自己的 Supabase 项目里，不需要账号密码；同步码就是钥匙，看板与转盘共用同一个码。
    2. 首次连接点顶栏「设置同步码」→ 弹窗会自动填好一个随机码 → 点「连接并同步」→ 把这个码记下来。
    3. 换设备在新手机 / 电脑打开同一网址，点「设置同步码」填入同一个同步码即可继续。
    4. 保存方式勾选任务、抽签、打卡后会自动写回云端（约 0.6 秒防抖），顶栏显示「已同步」即成功；点一下同步状态可立即拉取云端最新数据。
    5. 找回同步码忘了码？点顶栏「同步码」按钮可直接查看 / 复制本机保存的码（默认打码，点「显示」展开）。若换过浏览器或清过缓存，请到之前连接过的设备查看，或在 Supabase SQL Editor 执行 select code from public.boards; 找回（去掉结尾的 #turntable 即看板同步码）。
    6. 断开与安全「断开本机同步」只清空本机显示、云端数据保留；同步码相当于密码，请不要公开。
